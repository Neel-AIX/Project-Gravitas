Project Gravitas is a orbital mechanics/astrodynamics simulator.

How to use:
1: download python 3.13

2: download required dependencies: NumPy 
Go to IDE terminal and run:
pip install numpy

The math: 
Force of Gravity:
This is given by Newton's Law of Universal Gravitation:
$ F_g = \frac{m_1m_2G}{r^2}$
where $m_1$ and $m_2$ are the masses of the two bodies, $G$ is the gravitational constant $6.67\cdot10^-11 \space \frac{Nm^2}{kg^2}$ 

From there we can derive all the other formulas (derivations are in the derivations.tex file)
